# Guide for buiding, installiog and using jaspSyntax
jaspSyntax is the R package that allows users to run the JASP analyses directly in R (Studio). It can load data from a R DataFrame, 
and run (most of) the JASP analyses. You can in fact just copy the R Syntax generated by JASP (click the 'R' icon in your analysis), 
and paste this code in your R (Studio) environment, and get the same results as if you were using JASP.

```R
jaspTTests::TTestIndependentSamples(
          data = <name of the R Data Frame>,
          version = "0.95",
          formula =  ~ contNormal + contGamma,
          descriptivesPlot = TRUE,
          group = ~ contBinom)
```

In this code jaspTTests::TTestIndependentSamples will call first a wrapper that explicitly sets all default values and checks the formula syntax.
Then it calls jaspSyntax:
- to load the R Data Frame,
- to load the QML form that defines the analysis options and check all constraints
- to run the analysis in R as if it was called from JASP
- to return the result as an R object.

You can then manipulate the tables and plot objects in R.

jaspSyntax has also special functions to generate the analysis R wrappers.

## Build jaspSyntax
jaspSyntax is not yet available as a binary. So it has to be compiled. For this it needs an extra library (the JASP syntaxInterface library), and thanksfully this one is already compiled for MacOS and Windows.
So if you want to use directly this extra library, just load and compile jaspSyntax from GitHub by using the remotes package:
```
remotes::install_github("jasp-stats/jaspSyntax")
```
This will automatically download the JASP syntaxInterface library from our server. 

If you need to compile this extra library, you need first to compile the Qt library statically.
For this:
- Load the sources from Qt Maintenance tool
- Create a subfolder in Qt (e.g BuildStaticRelease)
- In a command prompt, type the following:
```
./configure -release -static -opensource -confirm-license -prefix ../BuildStaticRelease -submodules qtbase,qtdeclarative,qtshadertools,qt5compat,qtpositioning
cmake --build . --parallel
cmake --install .
```
